f1-Race-Strategy-Simulator:

A Java-based Formula 1 Race Strategy Simulator designed to model essential components of an F1 racing environment using Object-Oriented Programming.

Features:
Driver and car management
Car performance ratings
Tire management (Soft, Medium, Hard)
Pit stop simulation
Circuit modeling
Object-Oriented Programming architecture

Technologies:
Java
IntelliJ IDEA
Object-Oriented Programming

Project Structure: 
Car.java – Models car specifications and performance ratings. 
Driver.java – Represents Formula 1 drivers. 
Tire.java – Models tire compounds and properties. 
Circuit.java – Represents racing circuits.
